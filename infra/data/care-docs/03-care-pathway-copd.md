# COPD Care Pathway (CP-COPD-001)

> **Fictional training document.** Synthetic content for a workshop. Not clinical guidance.

## COPD-1 Scope

COPD-1.1 Applies to adults admitted with an exacerbation of chronic obstructive pulmonary disease.

COPD-1.2 Ward of reference: Respiratory 2A.

## COPD-2 Discharge coordination checklist

COPD-2.1 Inhaler technique reviewed and documented by the respiratory nurse.

COPD-2.2 Steroid course end date recorded (for example prednisolone), so that primary care knows
when the course stops.

COPD-2.3 Home-oxygen assessment result recorded. A new home-oxygen order (`HOME-O2`) requires a
prior-authorization check (PA-001).

## COPD-3 Follow-up requirements

| Follow-up | Deadline | Reference |
|---|---|---|
| Pulmonology clinic review | within **14 days** of discharge | FU-001 §FU-3 |
| Pulmonary rehabilitation referral | created **before discharge**; programme start within 28 days | COPD-4 |
| Primary care review | within **14 days** of discharge | FU-001 §FU-3 |

## COPD-4 Pulmonary rehabilitation

COPD-4.1 Every patient discharged after a COPD exacerbation is offered pulmonary rehabilitation
(procedure code `PULM-REHAB`).

COPD-4.2 The referral is created with urgency `routine` unless the respiratory team requests
`urgent`.

COPD-4.3 Several payers require prior authorization for `PULM-REHAB` (for example Contoso Care
Insurance — see PA-001). The coordinator checks this before the patient leaves the ward.

## COPD-5 Procedures commonly ordered after discharge

| Procedure code | Description |
|---|---|
| `PULM-REHAB` | Pulmonary rehabilitation programme (8 weeks) |
| `PULM-PFT` | Pulmonary function test |
| `HOME-O2` | Home oxygen therapy |

## COPD-6 Escalation

COPD-6.1 Increasing breathlessness at rest, confusion or blue lips are emergencies — escalate
immediately (SAFE-001 §SAFE-ESC-01).
